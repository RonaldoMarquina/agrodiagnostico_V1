# Condiciones registradas para el checkpoint ImageNet v1.4.2

Registro: 2026-11-23.

- El código TorchVision se publica bajo BSD-3-Clause.
- Los pesos preentrenados pueden estar sujetos a términos derivados del dataset
  con el que fueron entrenados; BSD-3-Clause no se atribuye al checkpoint.
- ImageNet declara uso de imágenes para investigación y educación no comercial
  y advierte que no posee el copyright de las imágenes.
- Decisión del proyecto: uso exclusivamente académico, de investigación y
  educación no comercial. No promover ni aprobar este candidato para uso
  comercial.
- El archivo `.pth` no se versiona ni redistribuye. Se conserva solo en
  almacenamiento privado local verificado.

- https://github.com/pytorch/vision/blob/v0.29.0/LICENSE
